# Real Estate Price Prediction

Using the power of AI to predict real estate prices.

## 🌟 About the Project

This section provides a detailed overview of the project. Explain its core **purpose**, the **problem** it solves, and the primary **features**.

Real Estate Price Prediction is a Python project designed to predict California home prices using a dataset of 20,000+ records. 
It uses a regression model to consider a number of factors to accurately predict prices for incoming California homes. Improved prediction accuracy through feature selection and data normalization. It eliminates the need for appraisers and makes appraising a home more objective to get an accurate home value.

## 🛠️ Installation

Follow these steps to get your local development environment set up.
1.  Download both 'CaliforniaRealEstate.ipynb' and 'housing.csv'.
2.  Open 'CaliforniaRealEstate.ipynb' in any environment that supports Jupyter notebooks (i.e. Anaconda, Google Colab).
3.  Add 'housing.csv' to the local environment folder.
4.  Run code node by node.
5.  In the 'model.predict' function, change X, y variants to your liking (predictions = model.predict([ [X, y] ]).
